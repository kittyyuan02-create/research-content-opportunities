# 选题机会研究员

结合用户需求、时间节点、平台热点与品牌造势，用证据筛选可执行的内容选题。适用于不同产品、行业、社交平台与内容形式。

## 使用方式

将本仓库完整下载，保留 `SKILL.md`、`references/`、`agents/` 和 `assets/` 的相对目录结构，按目标应用的自定义 Skill 安装方式导入。各应用实际支持的配置和导入方式可能不同；研究范围取决于应用具备的联网及数据访问能力。

示例指令：

> 使用「选题机会研究员」，为【产品】调研【平台】未来两周的选题，目标是【目标】，制作条件是【条件】，提供证据、品牌动作、具体切口与优先级。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `SKILL.md` | 核心工作流、选题判断及交付检查 |
| `references/evidence-protocol.md` | 采集、指标、计算、证据与数据缺口规范 |
| `references/output-templates.md` | 研究简报、品牌记录、选题卡及发布复盘模板 |
| `agents/openai.yaml` | 应用显示名称、默认提示词与配置 |
| `assets/icon.svg` | Skill 图标 |

## 工作流程

明确任务 → 四线发现候选 → 核验数据和案例 → 用户与传播分析 → 品牌动作与商业接入 → 生成与筛选选题 → 交付与复盘。

本仓库中的五个 Skill 原始文件直接来自 ChatGPT 导出包，保留原内容。README 为仓库使用说明。
