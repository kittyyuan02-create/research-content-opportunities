# 选题机会研究员

先从平台动态、跨行业大品牌、同行与替代方案发现内容机会，再结合自身品牌，形成有证据的产品接入与内容转译方案。适用于不同产品、行业、平台和内容形式。

## 使用方式

将本仓库完整下载，保留 `SKILL.md`、`references/`、`agents/` 和 `assets/` 的相对目录结构，按目标应用的自定义 Skill 安装方式导入。各应用实际支持的配置和导入方式可能不同；研究范围取决于应用具备的联网及数据访问能力。

示例指令：

> 使用「选题机会研究员」，为【产品】调研【平台】未来两周的选题，目标是【目标】，制作条件是【条件】，先探索平台、大品牌、同行及替代方案，再结合自身品牌，提供证据、用户洞察、产品切口、形式转译与优先级。

## 工作流程

明确任务 → 平台动态 → 大品牌动作 → 同行与替代方案 → 自身品牌 → 用户需求与机会归纳 → 产品接入 → 内容转译 → 排序、测试与复盘。

需求、时间节点、传播机制与反馈贯穿研究。参考内容可为图文、露脸视频、广告或非产品内容；最终方案按任务要求转译，不因参考形式不同而提前排除。

本 Skill 最初来自 ChatGPT 导出包，已按实际使用反馈更新检索发现、产品筛选与形式转译规则。仓库和新版安装包包含更新后的规则。ChatGPT 中既有安装需另行更新，不会随 GitHub 提交自动同步。
