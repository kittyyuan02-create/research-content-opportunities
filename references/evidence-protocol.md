# 数据与证据口径

## 采集
记录平台、地区语言、时区、观察与发布区间、采集时间、来源、查询词/话题ID、排序筛选、翻页/滚动范围、原始数、相关样本数、去重数、缺失值与相关性标准。
按内容ID去重，保留不同查询关联，跨词汇总不重复计数。按范围与决策需要定样本量，明确实际完成量。综合/个性化排序属于便利样本，样本高表现占比不是平台爆款率。

## 六组指标
| 维度 | 记录与解释 |
| --- | --- |
| 规模 | 内容总量、搜索指数、话题浏览分别记录，注明平台/数据工具覆盖边界 |
| 变化 | 同来源、同定义、等长周期比较，保留绝对值和基数 |
| 分布 | 高表现量/占比、独立作者数、粉丝规模、内容类型、近期连续性 |
| 基准 | 同作者相近形式、周期、观察龄的日常中位数，注明基准数量 |
| 反馈 | 赞藏评分享各自记录，编码咨询、质疑、跟做、无关讨论等 |
| 竞争 | 独立发布者、相似表达密度、品牌/竞品集中、重复与疲劳线索 |

内容量增长是供给信号，互动总量可能随供给增加；搜索需求另查。累计浏览不能当近期搜索量。无权重说明的词云只帮助发现关联表达。
高增长可能来自小基数；不可比较不同周期、形式、内容龄或平台而直接排名。

## 案例字段
记录ID、标题、链接、作者、当前粉丝、原发/编辑日期、采集时间、形式/时长、赞藏评分享、商业标注、关键画面/文案、评论主题、产品真实呈现、可迁移部分及限制。
当前粉丝不等于发布时粉丝；编辑时间不等于新发；搜到品牌名不等于实际使用，更不等于正面案例。先标题初筛，再核验重点案例。
“赞”、不可见、解析失败记缺失而非0。“1.4万”保留原文，数值为约14000。商业属性未知时写未知，不凭外观判断投流。

## 计算
- 环比=(本期-基期)/基期；基期为0或未知时不算常规百分比。仅有报告百分比则注明基数/口径未提供。
- 样本高表现占比=达到本轮阈值的相关去重样本/指标可读的相关去重样本。注明阈值、分母及缺失数；阈值不是平台官方标准。
- 互动率须有明确分母，如(赞+藏+评+分享)/播放。分享不可见则注明可见互动口径；无曝光/播放不能报互动率。
- “评论声量”按来源定义，不与单帖评论数或品牌提及次数混用。
- 相对日常提升须同指标和匹配基准；基准不可得保留报告说法，不反推。
- 单帖相对提升不能证明由热点导致，更不能证明销售效果。

## 证据与缺口
标注原帖实查/第三方报告/用户提供/分析推断/待验证创意，附日期与出处。多个独立近期相关案例、需求和产品可行性共同支持推荐；孤例可探索测试，不升级为全站趋势。
文章可能混用旧案例，分别记录文章与案例日期，查近期状态。营销心理归因作为假设验证。
缺少高级数据可做公开采样，但不能恢复全站总量、搜索指数、历史增长、投放占比。说明补数所需字段；勿因此放弃可行工作。
宿主无浏览时用提供材料分析或给研究方案，明确尚未完成当前站内验证，不能伪造实时发现。
